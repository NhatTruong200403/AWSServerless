Tạo mới dự án

Hướng dẫn tạo mới dự án AWS Serverless CDK (TypeScript)

Phần này hướng dẫn chi tiết từng bước để tạo project CDK demo (TypeScript), cài đặt các package cần thiết và chuẩn bị môi trường để có thể synth/deploy sau này. Bạn có thể sao chép nguyên khối lệnh vào terminal khi cần.

1. Tạo thư mục dự án và di chuyển vào thư mục

mkdir aws-serverless-demo && cd aws-serverless-demo

Mục đích: Tạo thư mục riêng để chứa file CDK, Lambda, cấu hình và các tài nguyên khác.

2. Khởi tạo dự án CDK với TypeScript

cdk init app --language typescript

Lệnh này sẽ tạo cấu trúc dự án CDK bằng TypeScript, bao gồm các thư mục và file mặc định như bin/, lib/, package.json, tsconfig.json.

3. Cài đặt dependencies cần thiết

Chạy lệnh sau trong thư mục dự án:

npm install aws-cdk-lib @aws-cdk/aws-apigatewayv2 @aws-cdk/aws-apigatewayv2-integrations @aws-cdk/aws-lambda-nodejs @aws-cdk/aws-dynamodb @aws-cdk/aws-iam jsonwebtoken @aws-sdk/client-dynamodb constructs esbuild

Mô tả ngắn về các package:

  • aws-cdk-lib: Thư viện CDK v2 (construct L1/L2)
  • @aws-cdk/aws-apigatewayv2 & @aws-cdk/aws-apigatewayv2-integrations: Constructs cho HTTP/WebSocket API
  • @aws-cdk/aws-lambda-nodejs: Hỗ trợ build Lambda Node.js với esbuild
  • @aws-cdk/aws-dynamodb: Constructs cho DynamoDB
  • @aws-cdk/aws-iam: Constructs tạo IAM Role/Policy
  • jsonwebtoken: Xử lý JWT trong Lambda
  • @aws-sdk/client-dynamodb: AWS SDK v3 cho DynamoDB
  • constructs: Runtime dependency cho CDK
  • esbuild: Công cụ build nhanh cho Lambda Node.js

Lưu ý: Một số module như API Gateway V2 có thể ở trạng thái alpha tuỳ phiên bản CDK.

4. (Tuỳ chọn) Cài đặt devDependencies cho TypeScript

Nếu cdk init chưa tạo sẵn:

npm install --save-dev typescript ts-node @types/node

5. Bootstrap CDK

Chỉ cần thực hiện một lần cho mỗi tài khoản/region.

  • Mặc định:
cdk bootstrap
  • Chỉ định account/region cụ thể:
cdk bootstrap aws://<ACCOUNT_ID>/<REGION> --profile <PROFILE_NAME>

Ví dụ:

cdk bootstrap aws://123456789012/ap-southeast-1 --profile MyProfile

Bootstrap sẽ tạo S3 bucket, roles và các tham số SSM cần cho CDK deploy.

6. Thêm script tiện ích vào package.json

"scripts": {
  "build": "tsc -p tsconfig.json",
  "watch": "tsc -w -p tsconfig.json",
  "synth": "cdk synth",
  "deploy": "cdk deploy",
  "destroy": "cdk destroy"
}
  • npm run build: Biên dịch TypeScript
  • npm run synth: Sinh CloudFormation template
  • npm run deploy: Deploy stack lên AWS
  • npm run destroy: Xoá stack và tài nguyên

7. Kiểm tra ban đầu

Biên dịch TypeScript:

npm run build

Sinh template:

npm run synth

Deploy (nếu đã bootstrap và cấu hình AWS CLI):

npm run deploy -- --profile <PROFILE_NAME>

8. Cấu trúc thư mục khuyến nghị

aws-serverless-demo/
├─ bin/
│  └─ aws-serverless-demo.ts
├─ lib/
│  └─ aws-serverless-demo-stack.ts
├─ package.json
├─ tsconfig.json
└─ cdk.json

9. Các vấn đề thường gặp

  • Phiên bản Node.js: >= 20
  • CDK CLI & aws-cdk-lib: Nên đồng bộ phiên bản
  • Lỗi credentials: Kiểm tra aws configure hoặc AWS_PROFILE
  • Lỗi bundling Lambda: Đảm bảo đã cài esbuild
