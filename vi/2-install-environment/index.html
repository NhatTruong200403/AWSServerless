Cài đặt môi trường

Hướng dẫn cài đặt môi trường phát triển Serverless trên AWS

Để triển khai, quản lý và phát triển các giải pháp Serverless trên AWS, bạn cần chuẩn bị đầy đủ các công cụ sau đây. Hướng dẫn này áp dụng cho cả Windows, macOS và Linux.

1. Cài đặt AWS CLI (Command Line Interface)

AWS CLI là công cụ dòng lệnh giúp bạn quản lý các dịch vụ AWS dễ dàng hơn.

  • Tải và cài đặt:

    • Windows:
      Tải file cài đặt, sau đó chạy file .msi để cài đặt.
    • macOS:
      Tải file cài đặt, sau đó chạy file .pkg để cài đặt.
    • Linux (x86_64): 
      curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

  • Kiểm tra cài đặt thành công:

    aws --version

    Nếu trả về phiên bản, bạn đã cài đặt thành công.

2. Cài đặt Node.js (Phiên bản 20 trở lên)

Node.js là môi trường chạy JavaScript cần thiết cho AWS CDK và các script triển khai.

  • Tải Node.js:

    • Truy cập https://nodejs.org/en/download/
    • Chọn bản LTS hoặc Current (yêu cầu >= 20.x.x)
    • Làm theo hướng dẫn cài đặt cho hệ điều hành của bạn.

  • Kiểm tra cài đặt:

    node --version

    Đảm bảo phiên bản >= 20.x.x

3. Cài đặt AWS CDK (Cloud Development Kit)

AWS CDK cho phép bạn định nghĩa hạ tầng AWS bằng code (Infrastructure as Code).

  • Cài đặt qua npm:

    npm install -g aws-cdk

  • Kiểm tra cài đặt:

    cdk --version

    Nếu trả về phiên bản, bạn đã cài đặt thành công.

4. Cấu hình AWS CLI để kết nối tài khoản AWS

Sau khi cài đặt AWS CLI, bạn cần cấu hình thông tin truy cập AWS.

  • Chạy lệnh cấu hình: 
    aws configure
  • Nhập các thông tin sau khi được yêu cầu:
    • AWS Access Key ID: Nhập Access Key của bạn (lấy từ IAM trên AWS Console)
    • AWS Secret Access Key: Nhập Secret Key tương ứng
    • Default region name: Ví dụ ap-southeast-1 (Singapore) hoặc khu vực bạn muốn triển khai
    • Default output format: json (hoặc yaml, text)

Lưu ý:
Không chia sẻ Access Key/Secret Key cho người khác. Nếu chưa có, hãy tạo mới trong phần IAM > Users > Security credentials.

5. Kiểm tra kết nối AWS CDK với tài khoản AWS

Sau khi cấu hình xong, kiểm tra kết nối bằng lệnh:

  • Kiểm tra danh sách stack hiện có: 
        cdk ls

Nếu lệnh trả về danh sách stack hoặc không báo lỗi xác thực, bạn đã cấu hình thành công.

6. (Khuyến nghị) Cài đặt thêm các công cụ hỗ trợ

  • Git: Quản lý mã nguồn (Tải tại đây)
  • Visual Studio Code: Trình soạn thảo mã nguồn mạnh mẽ (Tải tại đây)
  • AWS Toolkit for VS Code: Tiện ích mở rộng giúp quản lý AWS trực tiếp từ VS Code.
