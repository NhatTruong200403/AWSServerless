Testing with Postman, Curl, and Unit Test

1. Generate JWT Token for Testing

In this demo environment, our Lambda Authorizer uses JWT with the secret a-string-secret-at-least-256-bits-long and algorithm HS256.
You need to generate a valid token to test your requests.

Steps to generate a token:

  1. Go to https://jwt.io/.
  2. In the Header section, enter: 
    {
   "alg": "HS256",
   "typ": "JWT"
}
  3. In the Payload section, enter: 
    {
   "sub": "1234567890",
   "name": "John Doe",
   "admin": true,
   "iat": 1516239022
}
  4. In the Secret section:
    • Secret: demo-secret-key-12345
  5. Copy the generated token to use in Postman.

💡 You can set the token expiry as you wish (e.g., 15 minutes for demo).

2. Unit Test (Jest)

Install Jest

npm install --save-dev jest ts-jest @types/jest

Configure Jest for TypeScript (if not already)

npx ts-jest config:init

Create file lambda/handler.test.ts

import { handler } from './handler';

test('GET should return 200', async () => {
  const response = await handler({ httpMethod: 'GET' });
  expect(response.statusCode).toBe(200);
});

test('POST with invalid body should return 400', async () => {
  const response = await handler({ httpMethod: 'POST', body: '{}' });
  expect(response.statusCode).toBe(400);
});

Run unit tests

npx jest

3. Integration Test with Postman

3.1. GET (Check caching, auth, API Key)

  • Add Token: Add the generated JWT token.
  • Add key: Add the API key obtained from AWS Console > API Gateway > API Keys > Select key by ID > Show “API key”.

3.2. POST (Check validation)

  • Add Token: Add the token as above.
  • Add key: Add the API key as above.
  • Add Data: Add sample data to test the POST method.
   {
      "id":"demo1",
      "name":"test-item"
   }

3.3. Test Rate Limit using PowerShell or Terminal

  • Use a script to send >1000 requests/minute:
1..1100 | ForEach-Object {
    $headers = @{
        "Authorization" = "Bearer eyJhbGciOiJ....."
        "x-api-key"     = "VOj............"
    }
    try {
        $response = Invoke-WebRequest -Uri "https://rlkzdtjind.execute-api.ap-southeast-1.amazonaws.com/prod/items" -Method Get -Headers $headers -ErrorAction SilentlyContinue
        if ($response.StatusCode -eq 200) {
            Write-Output $response.StatusCode
        }
    } catch {
        Write-Output $_.Exception.Response.StatusCode.Value__
    }
} | Out-File -FilePath "output.txt"
  • Run the script: Run in PowerShell or Terminal.
  • Expected result:
  • 1100 requests without hitting the rate limit.
  • Open the output.txt file to check the results, there should be no 429 errors (Rate Limit Exceeded).

3.4. Test Invalid JWT

  • Send a request with an invalid JWT or leave the Authorization header empty:
  • Expect 401 Unauthorized or 403 Forbidden.

✅ Expected results:

  • Unit tests pass.
  • GET/POST work correctly with auth + API Key.
  • Cache works → latency decreases on the second call.
  • Rate limit
