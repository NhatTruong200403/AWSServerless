Monitoring Configuration and API Documentation

Configure and Check Monitoring (CloudWatch Logs)

AWS automatically enables monitoring for both Lambda Functions and API Gateway, making it easy for you to track and debug.

1. Check Logs

  1. Open the AWS Management Console.
  2. Navigate to CloudWatch.
  3. Select Log groups.
  4. Find the log groups:
    • /aws/lambda/DemoHandlerLambda
    • /aws/apigateway/DemoHttpApi/... (the full name will include the API Gateway ID)
  5. Click on the log group to view detailed logs.

2. Set Log Retention Period

By default, AWS retains logs indefinitely, which can increase storage costs. You should limit the log retention period.

  1. In the log group you want to configure:
    • Select Actions > Edit retention.
    • Choose 7 days (or another value that fits your needs).
    • Click Save.

💡 Tip: Only keep logs for as long as necessary to save costs.

Create Documentation with OpenAPI/Swagger

You can export your API Gateway configuration in OpenAPI 3 format to generate clear API documentation.

1. Export OpenAPI Spec from AWS Console

  1. Go to AWS Console > API Gateway.
  2. Select the ServerlessDemoApi API.
  3. Choose Stages > default.
  4. Click Export.
  5. Select Export as OpenAPI 3.
  6. Choose Export as YAML and save the file.

2. Import into Swagger UI

  1. Open Swagger Editor at: https://editor.swagger.io/
  2. Select File > Import file.
  3. Upload the exported YAML file or copy its contents into the editor.
  4. View and check endpoints, authentication, and descriptions.

💡 You can edit the YAML in Swagger Editor to add descriptions, examples, or more detailed information.

✅ Result: You will have a visual API document that is easy to share with developers or testers to understand and use
